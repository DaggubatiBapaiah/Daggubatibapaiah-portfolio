# Cinematic 3D Portfolio - Daggubati Bapaiah Chowdary

A premium, cinematic personal portfolio built with React, Three.js, and Framer Motion.
Designed to showcase engineering depth, AI capability, and creative design.

## 🚀 Tech Stack

- **Framework**: React (Vite)
- **3D Engine**: Three.js, React Three Fiber, React Three Drei
- **Animation**: Framer Motion, GSAP (capable)
- **Styling**: Vanilla CSS (Variables, Glassmorphism), Lucide React (Icons)
- **Font**: Outfit (Sans), Space Grotesk (Mono)

## 🛠 Setup & Run

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## 📂 Structure

- `src/components/Background3D.jsx`: The immersive starfield background.
- `src/components/ProjectCard.jsx`: Interactive project cards with hover effects.
- `src/components/Modal.jsx`: Detail view for projects.
- `src/data/portfolio.js`: Content data (Profile, Projects, Certifications).
- `src/index.css`: Global design system (Colors, Typography).

## 🎨 Customization

Edit `src/data/portfolio.js` to update content without touching the code.
Change theme variables in `src/index.css` to adjust the color palette.
